# Hi, I'm Laksh Meghani 👋

Backend & Cloud Developer. I treat architecture as the real product — code is just where it becomes visible.

## How I Work

- **Architecture before syntax** — I understand the system before I touch the editor.
- **Clean & organized code** — structure isn't a nice-to-have, it's the baseline.
- **Zero tolerance for sloppy code** — debt is a decision, not an accident.
- **Framework-aware, not framework-bound** — I adapt patterns to the project, never force-fit.
- **Keeping pace** — actively tracking language and ecosystem evolution, not just shipping in one.
- **Documentation as craft** — a codebase that explains itself is the actual art of programming.

## Focus Areas

- ⚙️ Backend Development
- ☁️ Cloud Infrastructure & Deployment
